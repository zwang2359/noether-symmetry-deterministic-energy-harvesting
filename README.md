# Noether Symmetries Generate Deterministic Energy Harvesting Protocols

This repository contains the Python implementation and simulation code for the paper:
“Noether Symmetries Generate Deterministic Energy Harvesting Protocols.”

## 📌 Project Overview

This project numerically illustrates how Noether symmetries generate families
of source states that achieve the same deterministic energy-harvesting
transition. The simulations include the examples studied in the main text and
Supplemental Material.

## 📁 Repository Structure

- `Five spin chain model for DEH with Noether's theorem.ipynb` — Briefly describe the first example with the five-spin chain.
- `Classical DEH example with Noether's theorem.ipynb` — Briefly describe the second simulation with a classical DEH model.
- `requirements.txt` — Python packages required to reproduce the simulations.

## 🚀 How to Run the Simulations

1. Clone the repository:

```bash
git clone https://github.com/zwang2359/noether-symmetry-deterministic-energy-harvesting.git
cd noether-symmetry-deterministic-energy-harvesting
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Open the relevant Jupyter notebook and run all cells.
